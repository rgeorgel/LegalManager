Dúvidas

Perguntas frequentes

É grátis mesmo? Preciso de cartão?
É grátis e não pede cartão. Você cria a conta só com nome, e-mail e senha e começa a usar na hora.
O que acontece depois dos 15 dias do Plus?
Sua conta volta automaticamente para o plano Free, sem nenhuma cobrança. Seus processos, clientes e tarefas continuam lá. Se quiser manter os recursos do Plus, é só assinar dentro do sistema.
Funciona no celular?
Sim. O Causify funciona no navegador do celular, tablet ou computador, sem instalar nada.
Meus dados e os dos meus clientes ficam seguros?
Sim. Todas as conexões usam criptografia SSL/TLS, as senhas são armazenadas com hash, os dados de cada escritório ficam separados e há backup diário. O tratamento de dados segue a LGPD.
Serve para quem está começando na advocacia?
Sim. O plano Free é gratuito para sempre e cobre o essencial para organizar os primeiros processos e clientes. Quando o volume crescer, você muda de plano sem perder nada.
Posso cancelar quando quiser?
Sim. Os planos pagos podem ser cancelados a qualquer momento, sem multa, e seus dados ficam disponíveis para exportação.
